# Playlist-Maker

Приложение для создания плейлистов из любимых песен с использованием ITunes API.

## 🚀 Возможности

- **Поиск треков**: Поиск выполняется по названию трека, введенного в строку поиска
- **Плеер**: Прослушивание 30-секундных отрывков треков с возможностью воспроизведения и паузы
- **Избранное**: Добавление и удаление треков из избранного с помощью "сердечка"
- **История поиска**: Просмотр ранее открытых треков на экране поиска при пустой строке. Историю можно очистить
- **Управление плейлистами**:
  - Создание плейлистов с возможностью выбора изображения из памяти телефона и добавления описания
  - Добавление треков в существующие плейлисты
  - Просмотр всех плейлистов во вкладке "Плейлисты"
  - Удаление треков долгим нажатием
  - Редактирование, удаление плейлистов и возможность делиться ими
- **Настройки**: Изменение темы приложения, возможность поделиться приложением, связь с поддержкой и пользовательское соглашение

## 🛠️ Технологии

- **Kotlin** - основной язык разработки
- **ITunes API** для поиска музыки
- **Retrofit2** для сетевых запросов
- **Single Activity** подход
- **Android Jetpack Components**:
  - ViewModel - для управления UI-данными
  - StateFlow - для наблюдения за изменениями данных
  - Room - для локального хранилища данных
  - Navigation Component - для навигации между экранами
- **Koin** для зависимостей
- **Glide** - для загрузки и кэширования изображений
- **Flow и Coroutines** для многопточности

## 📦 Установка

1. Клонируйте репозиторий.

2. Откройте проект в Android Studio.

3. Запустите приложение на эмуляторе или физическом устройстве

## 🎯 Использование
Поиск музыки: На главном экране введите название трека в строку поиска

Добавление в избранное: Нажмите на "сердечко" рядом с треком

Создание плейлиста:

Перейдите во вкладку "Плейлисты"

Нажмите "Создать плейлист"

Добавьте название, описание и изображение

Нажмите "Сохранить"

Добавление треков в плейлист: Нажмите на трек и выберите "Добавить в плейлист"
